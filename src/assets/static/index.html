압축한 앱 파일을 선택

선택한 앱을 읽기 전용으로 검사합니다. AI 호출이나 클라우드 자원 생성은 하지 않습니다.



Sky가 선택한 커밋의 소스를 가져옵니다. 비공개 저장소와 파일·브랜치 페이지 링크는 아직 지원하지 않습니다.
Sky 서버가 켜져 있는 동안 브랜치를 약 1분마다 확인합니다. AWS를 선택하면 재배포에도 클라우드 비용이 발생합니다.


지원하는 앱 형식과 업로드 제외 항목
Node.js 앱은 package.json, Python 앱은 루트의 server.py·app.py·main.py가 필요합니다. app 객체를 서버로 실행할 때는 requirements.txt에 ASGI용 uvicorn 또는 WSGI용 gunicorn을 명시하세요. 그 외 런타임 앱은 Dockerfile이 필요합니다. .env, .git, node_modules 등은 업로드하지 않습니다.


02배포 설정


같은 앱 ID의 배포 이력을 묶습니다.
정적 사이트는 전용 스택을 만들며, 재배포 전 기존 릴리스를 종료해야 합니다.


대상별로 독립 검증하며 한 곳이 실패해도 다음 대상으로 진행합니다. Local Docker 다음 AWS에서는 로컬에서 검증한 동일 이미지를 승격합니다. 환경변수가 필요한 앱은 AWS 배포 전에 값을 다시 입력받습니다. Sky 작업 기록에는 값을 저장하지 않지만 AWS 서비스 설정에는 전달됩니다. 현재 다중 대상은 데이터베이스 없는 앱만 지원합니다.




앱 ID로 소유 RDS를 배포 시 자동 조회합니다. 아래 조회는 배포 전 상태 확인용이며 네트워크 값을 직접 입력할 필요가 없습니다. 이 앱 ID로 이미 만든 RDS만 연결합니다. 새 DB는 생성하지 않으며, 앱에는 migrations/ SQL 파일과 PGHOST·PGUSER·PGPASSWORD·PGDATABASE 방식의 연결이 필요합니다. ECS 서비스·로드 밸런서 비용과 기존 RDS 비용이 발생합니다. 앱 종료 후에도 RDS와 데이터는 남습니다.
 
서버에는 AWS 계정 ID와 이 앱 전용 서비스 보안 그룹 설정 또는 검증된 앱 네트워크 스택이 필요합니다. 배포 요청 전에 서버가 기존 DB 소유권과 네트워크를 확인합니다.
새 PostgreSQL RDS 생성 계획 미리보기
계획 조회는 DB를 생성하지 않습니다. 생성 버튼은 계획 확인 후에만 활성화됩니다. 같은 앱 ID의 스택 기록이 있으면 새 DB 계획을 거부하므로 기존 RDS 조회를 사용하세요. 먼저 앱 전용 서비스 보안 그룹을 서버에 지정하거나 앱 네트워크 스택을 준비하세요. ZIP이나 폴더를 선택한 뒤 “RDS 생성 후 앱 배포”를 누르면 소스·SQL을 먼저 검사하고, DB 생성이 확인된 후 같은 작업에서 배포합니다. 생성된 RDS는 앱 배포 실패·취소·종료 후에도 보존되고 비용이 계속 발생합니다. 서버가 중단되거나 생성 결과가 불확실하면 자동 재시도하지 않습니다. 예상 금액은 RDS 인스턴스 730시간과 20 GiB 저장소 용량만 포함합니다.
   


기존 또는 새 RDS를 선택해야 합니다. 2 MiB 이하의 SQLite 파일 하나, 단순 INTEGER·TEXT 테이블만 지원합니다. 원본은 보존하고 앱 코드 변경·이전 SQL 실행·HTTP 검증이 모두 끝나야 성공합니다. 기존 RDS에 같은 테이블이 있으면 이전이 실패하며 DB는 유지됩니다.


Local Docker와 같은 PC의 Compose에서 지원합니다. 단일 DB 파일과 절대 WORKDIR가 있는 Dockerfile만 지원합니다. 볼륨은 앱 ID별로 생성되고 배포 종료 후에도 남습니다. 기존 배포가 활성 상태이면 같은 DB의 동시 쓰기를 막기 위해 재배포를 거부합니다.


기존 RDS 수동 스냅샷
앱 ID의 기존 Sky RDS만 백업합니다. 계획 확인은 읽기 전용입니다. 생성한 수동 스냅샷은 삭제 전까지 남고 백업 저장 비용이 발생할 수 있습니다.
  


PostgreSQL RDS 폐기
실행 중인 앱·작업이 DB 비밀을 사용하면 중단합니다. 최종 암호화 수동 스냅샷이 사용 가능해진 뒤에만 DB와 RDS 스택을 삭제합니다. 자동 백업은 삭제되고, 기존·최종 수동 스냅샷과 앱 네트워크는 남아 저장 비용이 계속 발생할 수 있습니다. 중단된 작업은 자동 재시도하지 않습니다.
 


앱 전용 AWS 네트워크 준비
서버에 고정 서비스 보안 그룹이 없을 때 이 앱 ID의 ECS 서비스 보안 그룹을 만듭니다. 계획 확인은 읽기 전용이며 생성 버튼을 누를 때만 CloudFormation 스택을 생성합니다. 그룹은 앱 종료 후에도 남습니다.
  


원본 앱은 유지됩니다. 배포 중 코드 일부와 실행 로그를 AI에 전송하므로 직접 만든 앱을 사용하세요.
